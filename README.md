Este es un proyecto de [Next.js](https://nextjs.org) generado con [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Cómo empezar

### Primero, instalar dependecia necesarias:
```bash
pnpm add next-themes clsx tailwind-merge @heroicons/react gsap
```


### Segundo, ejecutá el servidor de desarrollo:
```bash
pnpm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) con tu navegador para ver el resultado.

Podés empezar a editar la página modificando `app/page.tsx`. La página se actualiza automáticamente a medida que editás el archivo.
